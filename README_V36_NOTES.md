# V36 — Command Center compact UI

Objectif : adapter le centre de commandement à une lecture rapide, avec une structure plus proche d'un tableau de bord professionnel.

Changements :
- Nouveau tableau de bord compact : visites, finances, Ghosts actifs, attente, volume suivi.
- Navigation rapide plus propre.
- Grandes sections transformées en panneaux repliables.
- Moins de scroll vertical : les informations détaillées se déplient au clic.
- CSS renforcé desktop/mobile pour éviter les colonnes trop fines et les barres disgracieuses.
- Journal financier limité visuellement, avec scroll interne uniquement si beaucoup d'entrées.

Note : cette version ne change pas la base Supabase. Elle améliore surtout l'interface et l'organisation visuelle.
